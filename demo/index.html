A race-results page where every finisher can turn their official time into a transparent PNG sticker for stories, messages, and mobile share sheets.

Client profile

Race day data, built for the phone.

Grand 5km Run is a compact finish-line demo: official-looking results first, then a one-tap PNG workflow for each runner.

The page keeps the table normal and accessible. The generated sticker stays hidden until a finisher taps their row action.

How to use the library

Compose the PNG, then hand it to the browser.

Import composePngBlob from story-sticker-kit/browser, pass a transparent source image, then place runner text with pixel-based text layers. Each layer controls its box, font, color, alignment, line count, and shrink/wrap fitting.

On mobile, pre-render the PNG inside the user action and call sharePngBlobToInstagramStory. Browser JavaScript cannot force Instagram Stories to open directly, so the library uses the native share sheet. When sharing is unavailable, keep copy and download fallbacks visible. 

const blob = await composePngBlob({
  image: routeStickerPng,
  layers: [
    { text: runner.time, box: timeBox, color: "#fff" },
    { text: runner.participant, box: nameBox, color: "#fff" }
  ]
});

await sharePngBlobToInstagramStory(blob, {
  filename: "grand-5km-run-1.png"
});
